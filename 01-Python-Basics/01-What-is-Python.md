# 01 — What is Python?

## Simple Meaning
Python is a high-level, general-purpose programming language known for readable syntax and a large ecosystem.

```python
print("Hello, Ayan!")
```

### Why companies use Python
- Backend APIs and services
- Automation and scripting
- Data engineering and analytics
- AI/ML and MLOps
- Cloud automation with AWS SDKs
- Testing and developer tooling

## Key Features
- Easy to read
- Dynamically typed
- Cross-platform
- Large package ecosystem
- Strong community support

## Company Example
A Python script can read server metrics, detect failures, create a report, and send an alert automatically.

## Common Mistakes
- Python is case-sensitive: `print` is correct, `Print` is not.
- Strings need quotes: `"hello"`.
