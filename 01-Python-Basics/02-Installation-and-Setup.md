# 02 — Installation and Setup

## Goal
Install Python and create a clean development setup.

## Check Python
```bash
python --version
```
On some systems:
```bash
python3 --version
```

## Recommended Editor
Use VS Code with the Python extension.

## Create a Project
```text
python-learning/
└── main.py
```

`main.py`:
```python
print("Python setup is working")
```

Run:
```bash
python main.py
```

## Company Habit
Keep every project in its own folder and later use a virtual environment for dependencies.

## Common Mistakes
- Python is installed but not added to PATH.
- Running commands from the wrong folder.
- Using an old interpreter accidentally.

## Interview Question
What is the difference between the Python interpreter and a code editor?

## Practice
Create `hello.py`, run it from the terminal, and change its output.
