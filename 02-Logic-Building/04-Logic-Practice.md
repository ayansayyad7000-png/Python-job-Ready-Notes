## Company-Style Problem — Health Status
Given:

```python
cpu = 82
memory = 61
service_up = True
```

Rules:
- service down → `CRITICAL`
- CPU >= 90 or memory >= 90 → `CRITICAL`
- CPU >= 75 or memory >= 75 → `WARNING`
- otherwise → `HEALTHY`

Write clean `if/elif/else` logic.
